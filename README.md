# BelarusGuessor 2🗺️

Интерактивная географическая игра в стиле GeoGuessr по Беларуси. Угадывайте локации по панорамам улиц и получайте очки за точность!

![BelarusGuessor](https://img.shields.io/badge/Belarus-GeoGuessr-green) ![Version](https://img.shields.io/badge/version-1.0.0-blue) ![License](https://img.shields.io/badge/license-MIT-lightgrey)

## 🌟 Особенности

- **50+ уникальных локаций** по всей Беларуси
- **Реалистичный подсчёт очков** с экспоненциальным затуханием
- **Бонусы за скорость** ответа
- **Таблица рекордов** с сохранением в LocalStorage
- **Адаптивный дизайн** для мобильных устройств
- **Плавные анимации** и интуитивный интерфейс
- **Мультиплеер режим** (в разработке)

## 🚀 Быстрый старт

### Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/your-username/BelarusGuessor.git
cd BelarusGuessor

# Установка зависимостей для мультиплеера (опционально)
cd server
npm install

# Запуск сервера для мультиплеера
npm start

# Откройте index.html в браузере или используйте Live Server
